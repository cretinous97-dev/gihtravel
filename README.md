# GIH Tour and Travel

A Next.js 16 and Payload CMS site for GIH Tour and Travel, backed by Neon PostgreSQL and designed for Vercel. It includes editable travel content, customer accounts, booking records, Stripe Checkout, Resend email, and Vercel Blob media storage.

See [SETUP.md](./SETUP.md) for local setup, environment configuration, CMS seeding, deployment, and launch-readiness notes.
